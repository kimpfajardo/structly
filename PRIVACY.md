# Structly Privacy Policy

Effective date: July 15, 2026

Structly is a Chrome extension that audits the webpage a user chooses to analyze for page structure, accessibility, metadata, structured data, rendering risks, call-to-action clarity, and AI readiness.

## Data Structly handles

When the user selects **Audit Page**, Structly processes information from the active webpage that is needed to create the audit report. This can include:

- the page URL and title;
- the page's raw HTML and rendered website content;
- metadata, headings, landmarks, links, buttons, form-control labels, structured data, and related page-structure signals.

Website content can include information that appears on the page the user chooses to audit. Structly does not intentionally collect passwords, authentication cookies, payment details, or form-entry values.

## How Structly uses data

Structly uses this information only to create and display the requested audit report in the extension's side panel. The report and its underlying page snapshot are processed locally in the browser.

Structly does not use analytics, telemetry, advertising, tracking, profiling, or a user account system. It does not sell, rent, or share webpage data with third parties, and it does not use webpage data for any purpose unrelated to providing the audit.

## Network activity and retention

For each user-requested audit, Structly makes one direct request to the selected webpage to retrieve its raw HTML. That request is made to the webpage's own host, using the browser session where available; Structly does not send the retrieved data to a Structly-operated server.

Structly does not use Chrome storage, local storage, or a remote database to retain audit data. Audit data remains in the extension's active session only as long as needed to show the report and is discarded when the panel session ends or the user resets the report.

## Permissions

Structly requests access to webpages so it can inspect the particular page the user chooses to audit. It accesses page data only to provide the audit features described in this policy.

## Changes to this policy

If Structly's data practices change, this policy will be updated before the changed practice takes effect.

## Contact
